# Bike Sharing Data Analysis Dashboard ✨

Proyek ini adalah submission untuk kelas Belajar Analisis Data dengan Python. Dashboard ini dibangun menggunakan Streamlit untuk memvisualisasikan tren penyewaan sepeda berdasarkan kondisi cuaca dan pola jam penyewaan.

## Setup Environment - Anaconda

```
conda create --name main-ds python=3.9
conda activate main-ds
pip install -r requirements.txt
```

## Setup Environment - Shell/Terminal

```
mkdir proyek_analisis_data
cd proyek_analisis_data
pipenv install
pipenv shell
pip install -r requirements.txt
```

## Run streamlit app

```
streamlit run dashboard/dashboard.py
```
